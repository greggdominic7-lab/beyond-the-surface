BEYOND THE SURFACE — INSTALLABLE WEB APP

This is a ready-to-publish progressive web app (PWA), not an APK or an iPhone .ipa file.

TO INSTALL ON FRIENDS’ PHONES
1. Publish the five app files (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) together to an HTTPS static website. Hosting is required once for a shareable installation link.
2. Share the resulting HTTPS URL.
3. iPhone: open in Safari, Share > Add to Home Screen > Add (enable Open as Web App if shown).
4. Android: open in Chrome, menu > Install app / Add to Home screen.
5. Open once online to cache files; test by enabling airplane mode and reopening.

For free hosting, GitHub Pages or Cloudflare Pages are options. The game has not been published by ChatGPT.

LOCAL PREVIEW
Open index.html in a browser to try the game. The local file is not a proper PWA installation and local storage may behave differently.

CUSTOM DECKS
Card Studio saves edits locally in the browser. Export JSON decks as backup. Import replaces the current deck.
